HOW IT MAKES THE GUESS
Photo-only estimation
With no known-size reference, a photo has no absolute scale. This page uses common-size priors, aspect ratio, silhouette fill and optional reference-shape clues. Treat the displayed real-world units as estimates, not verified measurements.
No external model, library or AI endpoint is used. The existing /api/dimension endpoint is used only to propose visual regions; physical-size estimates are calculated in this page. Camera perspective, zoom and unknown object identity can cause large errors.
